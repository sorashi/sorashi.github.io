Programování nad distribuovanou pamětí, programový model MPI (vícevláknové procesy, komunikátory, 2-bodové blokující a neblokující komunikační operace, kolektivní operace), paralelní násobení hustých matic, paralelní mocninná metoda.

  • inter-komunikátory
  • intra-komunikátory
  • operace
    • 2-bodové / kolektivní
    • blokující / neblokující
    • základní 2-bodové (blokující)
      - MPI_Send(*buf, count, type, dest, tag, comm)
      - MPI_Recv(*buf, count, type, source, tag, comm, status) — status má číslo zdrojového procesu a tag (protože můžeme dát ANY_TAG, ANY_SOURCE)
      - Bsend, Ssend, Rsend — buffered, synchronous, ready
    • neblokující
      • MPI_Isend, Ibsend, Issend, Irsend
    • kolektivní
      • jeden-mnoho
        • one-to-all, OAB, MPI_Bcast
        • multicast, MC, MPI_Bcast
        • one-to-all-scatter, OAS, MPI_Scatter
        • all-to-one-gather, AOG, MPI_Gather
      • všichni-všem
        • all-to-all broadcast, AAB
        • = all-to-all gather, AAG, MPI_AllGather
        • all-to-all scatter, AAS, MPI_Alltoall
  • mapování matic na procesy
    • proužkově / šachovnicově
    • blokově / cyklicky / blokově-cyklicky
  • MMM
    • Cannonův systolický algoritmus — paměťově optimální
      • rotuje nad toroidy, řádky doleva (wrap-around), sloupce nahoru (wrap-around)
    • Foxův alg. — nerotuji (broadcastuji po řádcích), rotuji
  • mocninná metoda
    • řešíme iterativně násobením matice vektorem a normováním
    • ukládám výsledek iterace do
    • každý proces potřebuje celý vektor (AAB, AllGather)
    • Náhodné mapování: každý MPI node může mít nnz odkudkoliv
      • Worst case potřebuji celý vector a ukládám jakýkoliv prvek
      • memory
    • Řádkové mapování: pruhy velikosti
      • pořád potřebuji celý vector , ale ukládám do jednoho známého
      • (za ) memory
    • Šachovnicové: kostky s neúplným řádkem ani sloupcem
      • potřebuju jenom kousek , který odpovídá horiz. souřadnicím mé kostky ( memory)
      • začnu s kusy na diagonálních prvcích (protože celý sloupec bude chtít svůj kus )
      • sloupcový broadcast pro distribuci (OAB)
      • Každá kostka teď může udělat lokální MVM a drží tak příspěvek k prvkům odpovídající vertikálním souřadnícím kostky ( memory)
      • Nejlepší je teď udělat redukci příspěvků zpět na diagonálu, kde si potom udělám nasdílím mezi prvky diagonály a udělám norm.
      • Díky Reduce-Scatter nemusím mít víc místa pro y na diagonálních prvcích ? (idk)
    • Lanczos
